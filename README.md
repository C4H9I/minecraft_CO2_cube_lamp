# minecraft CO2 cube lamp

Датчик CO2 (MH-Z19C) на ESP8266


![img.png](images/img.png)

Список компонентов:
- Плата ESP8266 R1
- Датчик CO2 MH-Z19C(B)
- Дисплей OLED 0.96" SS1306
- RGB светодиод с общим катодом
- Резистор (100-220) Ом
- Провода
